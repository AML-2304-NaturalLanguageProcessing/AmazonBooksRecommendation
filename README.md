# Amazon Books Recommendation Model
# Neural Collaborative Filtering with Emotional and Review Embeddings

This project implements a cutting-edge Neural Collaborative Filtering (NCF) model designed for personalized recommendation systems. By integrating user-item interactions, emotional features, and review embeddings, the model provides highly accurate and meaningful recommendations.

## Key Features

- **Hybrid Model Architecture**: Combines Matrix Factorization (MF) for collaborative filtering with Multi-Layer Perceptrons (MLP) for feature-rich data.
- **Emotion-Aware Recommendations**: Incorporates emotional attributes of items to enhance user satisfaction.
- **Text Analysis Integration**: Utilizes review embeddings to capture the sentiment and semantic context of item reviews.
- **Scalability**: Supports large datasets with efficient data preprocessing and model training.

## Objective

The primary goal of this project is to develop a recommendation system that not only predicts user preferences accurately but also leverages additional contextual data such as emotions and text reviews. This approach ensures a deeper understanding of user behavior and delivers personalized experiences.

## Project Outcomes

- Enhanced recommendation accuracy through multi-modal data integration.
- Improved user engagement by incorporating emotional and textual features.
- A modular and extensible architecture suitable for various recommendation scenarios.
